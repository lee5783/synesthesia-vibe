# Contributing

Thank you for your interest in SynesthesiaVibe.

## How to help

- **Bugs and feature requests:** open an issue. Include the platform, the OS version, the SynesthesiaVibe
  version (the `VERSION` file or the release tag) and, for a rendering problem, the preset name.
- **Code changes:** open a pull request against `master` if a diff is the clearest way to describe the
  change. Keep it small and focused. Build the affected targets first, as described in
  [README.md](README.md#building-from-source).
- **Presets and textures:** do not submit presets or textures you do not have the right to redistribute.
  See [NOTICE](NOTICE) for the licenses of the content already included.
